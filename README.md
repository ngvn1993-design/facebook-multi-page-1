# Facebook Multi-Page — Windows App

Đây là bản đóng gói Electron của tool Multi-Page. Sau khi build thành installer `.exe`, người dùng chỉ cần cài đặt và mở app.

Tính năng:
- Đăng nhập Facebook trực tiếp
- Tải danh sách Fanpage người dùng có quyền quản lý
- Chọn nhiều Page
- Đăng text/ảnh/video
- Hẹn giờ cục bộ
- Xem kết quả từng Page
- Không yêu cầu người dùng nhập Page Access Token

Lưu ý: app dùng browser automation, nên Facebook có thể thay đổi giao diện làm selector cần cập nhật.
